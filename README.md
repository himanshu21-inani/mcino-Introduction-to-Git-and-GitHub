## Simple Interest Calculator

This project includes a Bash script (`simple-interest.sh`) that computes simple interest based on user input.

**Formula:** Simple Interest = (Principal × Rate × Time) / 100

**Input fields:**
- Principal amount (in currency units)
- Rate of interest (in %)
- Time period (in years)

**How to run:**
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

The script will prompt you for the principal, rate of interest, and time period, then display the computed simple interest and total amount.
