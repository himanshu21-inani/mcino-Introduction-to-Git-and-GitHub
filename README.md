# Introduction to Git and GitHub - Final Project

## Project Name
mcino-Introduction-to-Git-and-GitHub

## Description
This repository contains the final project for the Introduction to Git and GitHub course. It demonstrates fundamental Git and GitHub skills including forking a repository, cloning locally, making updates, staging and committing changes, pushing changes to a remote fork, and creating a pull request.
